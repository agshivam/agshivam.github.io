# Shivam Agarwal: portfolio site

Live at https://agshivam.github.io

A fast static site: one HTML file, no framework, no build step needed to view it. Sections: tools, results, career journey, client work, seven projects, and a contact form.

See `HOW_TO_UPDATE.md` for how to change anything.


## Build
React, Vite, TypeScript, Tailwind and Framer Motion. Source in `site-src/`, built files in the root. See HOW_TO_UPDATE.md.
